# Dataset

## Overview

This directory holds network measurement data for training and evaluating
the Random Forest classifier.

---

## Directory Structure

```
dataset/
├── raw/          — raw CSV files directly from experiments or synthetic generation
├── processed/    — cleaned, labelled, merged dataset ready for ML training
└── README.md     — this file
```

---

## Data Schema

Each CSV row represents one monitoring measurement interval.

| Column | Type | Description |
|--------|------|-------------|
| timestamp | ISO 8601 string | Measurement time |
| source | string | Source host (e.g., h1) |
| destination | string | Destination host (e.g., h4) |
| switch | string | Switch DPID or name |
| port | int | Switch port number |
| throughput_mbps | float | Measured throughput (Mbps) |
| delay_ms | float | ICMP round-trip / 2 (ms) |
| packet_loss_pct | float | Packet loss percentage (0–100) |
| utilization_pct | float | Link utilization percentage (0–100) |
| traffic_rate_mbps | float | tx_bytes delta / interval (Mbps) |
| queue_length | int | OVS queue depth (if available; else -1) |
| link_status | int | 1 = up, 0 = down |
| label | string | NORMAL / CONGESTION / FAILURE |

---

## File Naming Conventions

### Raw experiment data (real Mininet measurements)
```
raw/experiment_<YYYYMMDD_HHMMSS>_<scenario>.csv
```
Example: `raw/experiment_20260901_143022_congestion.csv`

### Synthetic data (pipeline testing only — NOT for final evaluation)
```
raw/synthetic_<description>.csv
```
Example: `raw/synthetic_sample_balanced.csv`

**IMPORTANT:** Synthetic data must NEVER be cited as real experimental results
in academic reports or performance comparisons.

### Processed (merged + cleaned for training)
```
processed/dataset_<YYYYMMDD>_<version>.csv
```
Example: `processed/dataset_20260915_v1.csv`

## Class Distribution (target)

For a reliable Random Forest model, aim for:
- ≥ 500 total samples
- ≥ 100 samples per class
- Balanced classes (within ~2:1 ratio)

If collected data is imbalanced, the training script will report this
and apply stratified splitting.

---

## Data Provenance

All real experimental data must include a provenance comment in the
first row or a companion `_meta.json` file:

```json
{
  "source": "mininet_experiment",
  "date": "2026-09-01T14:30:22",
  "topology": "campus",
  "scenario": "congestion",
  "duration_seconds": 300,
  "controller": "monitoring_controller.py",
  "notes": ""
}
```
